Este panel funciona íntegramente en tu navegador. Lee tu calendario y tus tareas directamente desde Google y no envía tu información a ningún servidor intermedio.

Configuración · una sola vez

Conectar con Google

Unos 4 minutos. Google exige que cada copia del panel se registre con su propia credencial; por eso estos pasos no se pueden saltar.

1
Crea el proyecto y activa las dos APIs

Cada enlace abre la pantalla exacta. Vuelve aquí al terminar.

Crear proyecto ↗ Activar Calendar API ↗ Activar Tasks API ↗
2
Crea la credencial

Pantalla de consentimiento tipo Externo, luego cliente de tipo Aplicación web.

Pantalla de consentimiento ↗ Crear cliente OAuth ↗
Orígenes de JavaScript autorizados
Ámbitos a declarar https://www.googleapis.com/auth/calendar.readonly https://www.googleapis.com/auth/tasks

Añade tu correo como usuario de prueba en la pantalla de consentimiento; si no, Google bloqueará el acceso.

3
Pega el ID de cliente

Es público por diseño: no es una contraseña.

Para no repetirlo en cada dispositivo

Abre config.js en tu repositorio, reemplaza la línea del clientId por esta y guarda. GitHub Pages la publicará sola.
