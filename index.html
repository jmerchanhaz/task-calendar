Configuración · una sola vez

Conectar con Google

Debes registrar el origen web de este panel en un cliente OAuth de Google.

1 · Crea el proyecto y activa las APIs
Crear proyecto ↗Activar Calendar API ↗Activar Tasks API ↗
2 · Configura OAuth

Crea un cliente de tipo Aplicación web. Configura la audiencia, los permisos y, si corresponde, los usuarios de prueba.

Configurar consentimiento ↗Crear cliente OAuth ↗
